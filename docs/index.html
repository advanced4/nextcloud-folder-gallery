Your folders, with a picture on the front.

A free userscript. No server installation. No extra account.

Install

  1. Choose one script manager.

    Get Tampermonkey or get Violentmonkey. Their official pages link to the stores for supported browsers. You only need one.

  2. Add the gallery.

    Install Folder Gallery

    Your script manager should open an installation confirmation. If you see source code instead, use the copy-and-paste option below.

  3. Open Nextcloud Files.

    Reload the page and browse a folder whose path contains poliigon. The gallery appears automatically and loads nearby previews. No setup is required.

On Chrome or Edge, your browser may ask you to enable userscripts for the extension. Follow your manager's official setup instructions. Desktop Chrome, Edge, and Firefox are the initial targets; other browsers are not yet verified.

What becomes a preview?

In a matching path, the script checks each immediate child folder for a PNG, JPG, or JPEG with preview or sphere anywhere in its filename. Path and filename matching ignore capitalization. If there are several, it picks the first in natural filename order, so Preview2.png comes before Preview10.png.

Keep the preview directly inside the asset folder. ZIP inspection, nested preview searches, and generated renders are not included. Folders without an image remain accessible. The normal file view is always available through the gallery toggle.

Previews use small Nextcloud thumbnails. Folders are checked as you scroll, and discovered image choices are cached in this browser. Changed folders are checked again; Refresh clears the current directory's cached choices.

Your files stay yours

The gallery reads folder listings and preview images from the Nextcloud site you are signed into. It never uploads, renames, or deletes your files. It does not send your server address, folder names, images, keywords, or login information to this website.

Script managers may contact this GitHub Pages site to check for code updates. There are no analytics, remote libraries, or third-party image services in the script. The public project contains no real library content or server addresses.

The discovery cache stays in your Nextcloud site's browser storage, separate for each account. It holds folder paths, file IDs, and change identifiers, not image copies or login details. Choices expire after 30 days, or 5 minutes when no image was found. Clearing Nextcloud site data removes the cache. Thumbnail image caching is controlled separately by your server's HTTP headers.

Optionally, change or disable matching through your script manager's menu on a Nextcloud Files page: Configure folder previews for this Nextcloud account. Custom keywords stay in your browser and take precedence over the default; existing settings are preserved on update. An empty keyword list disables previews. Disabling the script and reloading restores the normal page.
