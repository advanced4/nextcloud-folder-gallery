Install

  1. Choose one script manager.

    Get Tampermonkey or get Violentmonkey. Their official pages link to the stores for supported browsers. You only need one.

  2. Add the gallery.

    Install Folder Gallery

    Your script manager should open an installation confirmation. If you see source code instead, use the copy-and-paste option below.

  3. Open Nextcloud Files.

    Reload the page, choose Set up folder previews, and enter the folder path keywords you want to match. For example, materials, assets. These settings stay in your browser.

On Chrome or Edge, your browser may ask you to enable userscripts for the extension. Follow your manager's official setup instructions. Desktop Chrome, Edge, and Firefox are the initial targets; other browsers are not yet verified.

What becomes a preview?

In a matching path, the script checks each immediate child folder for a PNG, JPG, or JPEG with preview anywhere in its filename. Matching ignores capitalization. If there are several, it picks the first in natural filename order, so Preview2.png comes before Preview10.png.

Keep the preview directly inside the asset folder. ZIP inspection, nested preview searches, and generated renders are not included. Folders without an image remain accessible. If no previews are found, the normal file view stays visible.

Your files stay yours

The gallery reads folder listings and preview images from the Nextcloud site you are signed into. It never uploads, renames, or deletes your files. It does not send your server address, folder names, images, keywords, or login information to this website.

Script managers may contact this GitHub Pages site to check for code updates. There are no analytics, remote libraries, or third-party image services in the script. The public project contains no real library content or server addresses.

To change or disable matching, open your script manager's menu on a Nextcloud Files page and select Configure folder previews for this Nextcloud account. An empty keyword list disables previews. Disabling the script and reloading restores the normal page.
